# Archived Manifold rulesets

Rulesets here are **not** part of standard bootstrap or published platform docs. Kept for history and reference only.

| File | Why archived |
|------|----------------|
| `io.picolabs.manifold.skills_registry.krl` | Pre–pico-engine **1.8** directory of ruleset RIDs and MCP tool definitions for extending things. **Superseded** by engine **mesh MCP** and **dev MCP**, which expose tools from `channelSchema` / `picoSchema` without a separate registry pico. |

To use on a legacy mesh: install manually on a child pico via `wrangler:install_ruleset_request` (not supported in current bootstrap).
